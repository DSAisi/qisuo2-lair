# Lair · 家园页装修台

一个**单文件**的视觉配置器：给「两个人的空间」调外观，调完导出一份 JSON，交给做前端的人落地。

## 为什么是单文件

没有构建、没有依赖、不联网、不用起服务。双击 `index.html` 就能开。

调外观这种事，最怕「想看一眼效果得先装一堆东西」。所以它把预览和控制放进同一页：左边手机预览，右边控制，动一下立刻看到。

## 能调什么

| 类别 | 项 |
|---|---|
| 背景 | 纯色、渐变、图片、玻璃模糊 |
| 卡片 | 圆角、卡内留白 |
| 字体 | 苹方 / 宋体 / 楷体 |
| 文字 | 深浅 |
| 头像 | 两个位置，写字、emoji 或图片网址都行 |
| 心情 | 6 格颜文字，可换预设组，也可逐格自定义 |
| 显示 | 四张卡片各自显隐 |

## 那四张卡片

- 顶部联结卡（两个人 + 在一起多久）
- 今日心情（6 格颜文字）
- 今天概览
- 「他此刻的心里」

## 怎么用

1. 打开 `index.html`
2. 调到你满意的样子
3. 点「导出配置」，复制弹出来的 JSON
4. 把 JSON 交给做前端的人

## 为什么导出 JSON，而不是直接生成页面

**配置和内容是两件事。** 这个工具只管「长什么样」；「里面写什么」是另一个人的活。

分成两半之后：改配色不用碰文案，改文案不用碰样式。
